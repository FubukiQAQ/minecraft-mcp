# 测评任务：中国古典建筑群

**任务来源**：`benchmark/prompt_chinese_architecture.md`
**中心点**：`(-111, -1, -92)`（y = -1 为地表顶层）
**场地范围**：`x -139 ~ -83`，`z -120 ~ -58` → **57 × 63 格**（要求 ≥ 32×32）
**建造方式**：`tools/build-chinese-temple.mjs`，326 次 RPC 调用，0 失败

## 一、总体布局

单一中轴线（u = 0，即 x = -111）贯穿南北，所有建筑沿轴严格对称；
动线自南向北为 **山门 → 前院（钟楼/鼓楼夹峙）→ 中院（东西配殿）→ 主殿**。

| 建筑 | 面阔 × 进深 | 台基 | 通高 | 世界坐标中心 |
|---|---|---|---|---|
| 主殿 | 23 × 15 | 4 层（最高） | 22 | (-111, -, -107) |
| 东配殿 / 西配殿 | 11 × 13 | 3 层 | 13 | (-90 / -132, -, -85) |
| 钟楼（东） | 7 × 5，二层 | 3 层 | 19 | (-90, -, -65) |
| 鼓楼（西） | 7 × 5，二层 | 3 层 | 19 | (-132, -, -65) |
| 山门 | 23 × 5 | 3 层 | 14 | (-111, -, -62) |

主殿体量（23×15×22）约为钟鼓楼（11×11×19 外接）的 2.5 倍，且居北端核心位、
台基最高、出檐最深，主次关系明确。

## 二、建筑形制与选材

| 构件 | 选材 | 说明 |
|---|---|---|
| 台基 / 台阶 / 铺地 | 石砖、磨制安山岩 | 主殿 4 层台基 + 二级踏步 + 石栏杆 |
| 墙体 | 红混凝土 | 红墙，山门/配殿/主殿一致 |
| 立柱 / 额枋 | 深色橡木原木、深色橡木木板 | 木色构件，柱网含副阶周匝（主殿） |
| 斗拱层 | 深色橡木台阶块（半砖） | 出挑一层，形成檐下阴影 |
| 屋面 | 深板岩瓦 | 阶梯式收进，庑殿式四面出檐 |
| 正脊 / 垂脊 / 翘角 | 氧化铜 | 绿琉璃脊，四角起翘 |
| 门窗 | 玻璃板（隔扇/窗棂）+ 木板裙板 | 主殿明间开门，次间为隔扇 |
| 装饰 | 金块（匾额/宝顶）、灯笼、石砖楼梯（石狮） | 匾额 2 方、灯笼 8 盏、石狮 1 对 |

- **主殿**：副阶周匝柱廊 + 石栏杆 + 隔扇门 + 匾额 + 正脊鸱吻，屋面五层收进。
- **钟楼 / 鼓楼**：二层楼阁式，一层为开敞槛墙亭，二层攒尖顶 + 金宝顶；
  东钟楼悬 `bell`（自额枋下垂），西鼓楼置 `barrel` 作鼓 —— 东钟西鼓。
- **山门**：三开间，中门洞贯通，两尽间开直棂窗，门额金匾。
- **配殿**：东西对称，门开向中轴一侧，前后檐墙开窗。

## 三、庭院与配景

- 青砖铺满庭院，中轴设 7 格宽磨制安山岩甬道，两侧以雕纹石砖镶边，自山门直达主殿台阶。
- 丹墀前正中置石香炉一座。
- 四周红墙围合：石墙裙 + 红墙身 + 深板岩瓦压顶，南墙正中留山门开口。
- 院内植云杉 6 株（东西对称各 3 株）。

## 四、验证结果

1. **调用**：326 次 `set_block` / `fill_blocks` 全部成功，无异常。
2. **对称校验**：分别扫描西半场（u −28…−1）与东半场（u 1…28），
   19 项材质数量**逐项完全相等**，唯一差异为 `bell`（东）与 `barrel`（西），符合东钟西鼓的设计。
3. **数量对账**：每种方块的实测量均与脚本推导值吻合（例：云杉树叶 210 = 6 株 × 35；
   金块 14 = 主殿匾额 5 + 山门匾额 7 + 宝顶 2）。
4. **点位抽查**：正脊、鸱吻、匾额、门洞、屋檐、踏步、宝顶、钟、鼓、石狮、甬道等
   关键坐标逐一 `get_block` 核对，方块 ID 与 `properties`（如石狮 `facing=south`、
   钟 `attachment=ceiling`）均正确。

## 五、复现

```bash
MCPBRIDGE_CONFIG="D:/PCL2CE/.minecraft/versions/1.21.1-Fabric 0.19.5/config" \
  node tools/build-chinese-temple.mjs
```

脚本开头会先清空整个场地体积，因此可反复运行、结果幂等；
单次 `fill_blocks` 体积超过模组的 `maxFillVolume`（32768）时自动沿最长边二分切分。
